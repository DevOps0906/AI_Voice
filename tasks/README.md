## 교훈 (다음 작업에 그대로 적용할 것만, 20줄 이내 유지)
- 대량 생성은 1주차 시범 → 리뷰 → 나머지 병렬. 병렬 워커는 일차별 파일·주차별 venv·--out 리포트로 분리하고 공용 파일(index·리포트)은 팀장이 마지막에 합친다.
- 자기 확인 코드는 리뷰에서 가짜 통과가 반복해서 나왔다: 상수끼리 비교, 빈 목록 all()/every(), API 응답 res.ok 미확인 → 규칙 파일에 금지 패턴으로 먼저 적고 시작한다.
- 병렬 실행 중 시간 초과는 CPU 경합일 수 있다 → 한가할 때 다시 재고, torch는 set_num_threads로 제한.
