# task-013 번호 공=주차 보기 · 문제 풀이 일차 탭 · 자료실 왼쪽 메뉴

- 위험도: 보통 → builder(sonnet)
- 대상: `dashboard/index.html`만

## 1. 과정 지도 번호 공 (`#map-d{n}`) 수정
- 지금: 공 n → 그 일차 카드 1장만.
- 바꿈: 공 n → **그 일차가 속한 주차 전체**를 보여 준다.
  - "{week}주차 {module}" 제목 + 그 주의 일차 카드 전부(기존 주차 목록 카드 모양 그대로, 4~5장 한 줄), 선택 일차 카드 강조(테두리 `--a5`, aria-current).
  - 그 아래 선택 일차 상세 카드(지금 구현된 상세 카드: 목표·Part·버튼·Colab) 유지.
  - 같은 주의 다른 일차 카드를 누르면 `#map-d{그 일차}`로 바뀌어 상세만 교체(주차 카드는 그대로).
- 번호 공 줄에서도 선택 주차의 공들을 옅게 묶어 표시(선택 공은 채움, 같은 주 공은 연한 배경).

## 2. 문제 풀이 `#lib-quiz` 일차 탭
- "전체 일차"로 모든 일차를 위아래로 쌓지 않는다. **한 번에 한 일차만** 보여 준다.
- 해시: `#lib-quiz-w{w}-d{n}` (일차 생략 시 그 주 첫 일차, 주차 전체 `w0`이면 D1).
- 일차 칩 줄(D1 D2 …)은 **문제 목록 바로 위**에 두고 `position:sticky; top:0`(모바일은 레일 탭 높이 고려)으로 스크롤해도 보이게. 칩 = 그 주의 일차(전체 주차일 때는 1~N 전체, 가로 스크롤).
- 칩 옆/아래에 "◀ 이전 일차 · 다음 일차 ▶" 버튼(주차 경계를 넘어 이동, 주차 버튼도 같이 갱신).
- 맞힌 수/푼 수는 일차가 바뀌면 그 일차 기준으로 초기화.
- 개념 정리·그래프 정리·애니메이션 정리는 지금 구조 유지(일차 칩만 같은 sticky 스타일 적용 가능).

## 3. 자료실 왼쪽 메뉴(GNB) — `#lib-*` 4페이지 공통
- 데스크톱(1200+): 메인 영역 안에 왼쪽 보조 메뉴 220px + 본문. 보조 메뉴는 `position:sticky; top:16px`, 자체 스크롤.
  - 맨 위 "← 과정 지도".
  - 4항목: 개념 정리 · 문제 풀이 · 그래프 정리 · 애니메이션 정리(각 총계 작은 글씨). 현재 항목 강조(왼쪽 2px `--a5` 막대, 기존 레일 스타일).
  - 현재 항목 아래에 1~9주차 목록, 선택 주차는 펼쳐서 그 주 일차(D{n} 제목 한 줄, 말줄임) 표시. 주차/일차 클릭 → 해당 해시(문제 풀이는 `-d{n}`까지, 다른 페이지는 주차 + 그 일차 위치로 스크롤).
- 태블릿(768~1199): 보조 메뉴 180px, 일차는 번호만.
- 모바일(~767): 보조 메뉴 대신 본문 위 2줄 — 자료 4개 가로 탭 + 주차 select(또는 가로 스크롤 버튼). 가로 넘침 0.
- 기존 페이지 안 주차 버튼 줄은 데스크톱·태블릿에서는 숨기고(보조 메뉴가 대신), 모바일에서는 유지.

## 규칙
- 기존 토큰·Pretendard·반경 6px, 새 색 금지, 다크 모드. 터치 44px.
- 홈·다른 탭·`dashboard/d*/`·`data/`·`scripts/` 수정 금지. library.json 그대로 사용.

- `#lib-quiz-w1-d2` → D2 문제만, 칩 sticky, 다음 일차 → D3, D5에서 다음 → 2주차 D6.
