# task-016 그래프 라이브러리 비교 페이지 (D1 샘플)

- 위험도: 보통 (외부 CDN 라이브러리 = 새 노출 면, 비교용 독립 페이지) → builder(sonnet)
- 대상: 새 파일 `dashboard/lab/charts-d1.html` 하나 (index.html은 건드리지 않음 — task-015 진행 중)

## 목표
같은 D1 그래프 3종을 **라이브러리 5가지로 똑같이** 그려 사용자가 퀄리티를 비교한다.
라이브러리(최신 stable, 정확한 버전 고정, cdnjs 또는 jsDelivr):
1. Canvas 2D (라이브러리 없음, 기존 애니메이션 방식)
2. Chart.js
3. D3
4. Apache ECharts
5. Plotly.js
(라이선스: MIT·ISC·Apache-2.0만. 버전과 라이선스를 페이지에 표기)

## 그래프 3종 (D1 내용, 값은 "수업용 예시 값" 표기)
- **A. 샘플링**: 1 kHz 사인파(연속 곡선) + 8 kHz·16 kHz 샘플 점(토글), 2 ms 구간. 점이 하나씩 찍히는 등장 애니메이션.
- **B. 음성 에이전트 지연 예산**: STT 300 · LLM 700 · TTS 400 ms 가로 누적 막대 + 목표선 1500 ms, 막대가 차오르는 애니메이션, 마우스 올리면 툴팁.
- **C. 마이크 입력 파형(실시간)**: 합성 음성 신호(여러 사인파 + 잡음 + 포락선)를 초당 30프레임으로 흘려보내는 스트리밍 라인(최근 2초), 일시정지 버튼.

## 화면
- 위: 제목 "그래프 라이브러리 비교 · D1", 설명, 라이브러리 탭 5개(+ "나란히 보기" 탭: 같은 그래프를 5개 라이브러리 2~3열 격자로).
- 각 라이브러리 탭: A·B·C 3장 카드 + 카드마다 짧은 평가 메모 칸(코드 줄 수, 애니메이션 부드러움, 툴팁·확대 기본 제공 여부, 번들 크기 gzip KB — 실제 값).
- 아래: 비교 표(라이브러리 · 버전 · 라이선스 · 크기 · 코드 줄 수(A+B+C) · 애니메이션 · 상호작용 · 맞는 용도 · 추천도) — 수치는 실제로 잰 값.
- 기존 대시보드 토큰·Pretendard·다크 모드(대시보드 `index.html`의 :root 변수 복사), 반응형 3구간, 모바일 가로 넘침 0. 왼쪽 위 `← 대시보드로` 링크(`../index.html#home`).
- 그래프 색은 대시보드 accent 토큰(a1~a5)을 읽어 적용, 다크 모드 전환 시 다시 그린다.
