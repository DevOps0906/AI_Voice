# task-012 과정 지도 일차 번호 공 선택기

- 위험도: 보통 (상태가 붙는 화면) → builder(sonnet)
- 대상: `dashboard/index.html` (renderMap 영역만)

## 목표
과정 지도(`#map`)의 "주차별 일차" 영역에 **로또 번호 공처럼 생긴 선택 버튼**을 둔다: [전체] + 일차 수만큼 [1]…[N] (지금 45개, `course.json` 길이로 자동 생성).

## 동작
- 위치: 자료실 카드 아래, "주차별 일차" 제목 바로 아래.
- **전체**(기본): 지금처럼 주차별 일차 목록 전체.
- **번호 n**: 목록 대신 그 일차 카드 1장만 보여 준다 — `D{n} · {week}주차 {module}`, 제목, 학습 목표, Part 목록, 버튼 [오늘의 흐름 →][애니메이션][정리 퀴즈](`#d{n}-…`) + 실습 노트북 Colab. 일차 JSON은 `loadDay(n)`으로 그때 1개만 받는다.
- 선택 상태는 해시로 유지: `#map-d{n}` (전체는 `#map`). 새로고침·뒤로 가기 동작.
- 준비 안 된 일차 공은 비활성(흐리게, aria-disabled).
- 키보드: 공은 button, aria-pressed, 포커스 링.

## 모양
- 공: 원형 지름 40px(모바일 44px 터치), 숫자 굵게. 공 색 테두리·선택 시 채움은 그 주차 색(기존 렌더맵의 `AC[(week-1)%5]` 그대로) → 주차가 색으로 묶여 보인다. 전체 버튼은 알약형 `--a5`.
- 줄바꿈 flex-wrap, 간격 8px. 데스크톱 한 줄 약 20개 · 모바일 7개 정도, 가로 넘침 0.
- 기존 토큰만, 새 색 금지, 다크 모드 대비 정상.

## 금지
- 자료실(#lib-*)·홈·다른 탭 동작 변경, `dashboard/d*/`·`data/`·`scripts/` 수정.

- 공 개수 = course.json 길이 + 1.
