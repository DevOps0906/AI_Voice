# task-010 홈 대시보드 (메뉴 집합 화면)

- 위험도: 보통 (상태·데이터가 붙는 화면) → builder(sonnet)
- 대상: `dashboard/index.html` 한 파일

## 목표
첫 화면을 과정 지도가 아니라 **모든 메뉴가 모인 홈 대시보드**로 바꾼다. 가독성 좋고 깔끔하게(GitHub Primer 느낌, 기존 토큰·Pretendard·반경 6px 그대로, 새 색 금지).

## 라우팅
- `TABS` 맨 앞에 `['home','대시보드']` 추가, 해시 `#home`. 해시가 없거나 모르는 값이면 `home`.
- 왼쪽 위 제목 링크(`a.home`)는 `#home`, title "대시보드 홈으로 가기".
- 일차 탭(flow~quiz)으로 갈 때 `aiVoiceDash.lastDay`에 일차 저장(sset). 시작 시 저장값이 준비된 일차면 그 일차로 시작.
- 레일 번호는 1부터 다시 매긴다(대시보드=1 … 모션=10). ← → 이동도 그대로 동작.

## 화면 구성 (위에서 아래로)
1. **머리:** eyebrow "음성 AI 전문가 과정", h2 "학습 대시보드", lead "9주 · 44일 · 준비된 일차 N일".
2. **이어서 학습 + 진도 (데스크톱 2:1 두 칸, 태블릿·모바일 1칸)**
   - 왼쪽 카드: `D{n} · {week}주차 {module}` 라벨, 일차 제목(크게), 학습 목표 첫 2개(짧게), 과제 진행 막대(그 일차 체크 수/전체), 버튼 [오늘의 흐름 →](주 버튼) [애니메이션] [정리 퀴즈] + 실습 노트북 Colab 링크(files 중 colab 있는 것, 새 창).
   - 오른쪽 카드: "전체 진도" — 과제를 하나라도 체크한 일차 수 / 44 막대, 그 아래 **이번 주** 일차 칩(그 주 D번호, 현재 일차 강조, 체크 있으면 ✓). 칩 클릭 → 그 일차로 바꾸고 홈에 머무름.
3. **메뉴 카드 그리드** (h3 "메뉴"): 홈을 뺀 9개 메뉴 각각 카드. 카드 = 번호 배지 + 이름 + 한 줄 설명 + 현재 일차 기준 숫자 1개(예: 목표 5개 · Part 7개 · 애니메이션 9종 · 자료 4개 · 개념 9개 · 과제 1/3 · 퀴즈 40문항 · 과정 44일 · 모션 25종). 클릭 → 그 메뉴. 데스크톱 3열 · 태블릿 2열 · 모바일 1열, 카드 높이 일정, hover 시 테두리 `--a5`.
4. **주차 한눈에** (h3): 1~9주차를 한 줄씩(주차 · 모듈 · 일차 알약 D1~D5, 체크 있는 일차 ✓). 알약 클릭 → `#dN-flow`. "과정 지도 전체 보기 →" 링크.

## 규칙
- 데이터는 `course.json` + 현재 일차 JSON(`loadDay`)만. 44개 JSON을 한꺼번에 받지 않는다. 과제 체크 저장 형식은 기존 `aiVoiceDash.hw.dN`(약 501행 renderTasks) 그대로 읽는다.
- 색·크기는 기존 CSS 변수만. 반응형 3구간(~767 / 768~1199 / 1200~), 모바일 가로 넘침 0, 터치 44px.
- 기존 탭들의 동작·모양은 바꾸지 않는다. 애니메이션 파일(`dashboard/d*/`)은 건드리지 않는다.
