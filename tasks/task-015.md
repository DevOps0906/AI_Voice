## 1. 코드: 위치를 바로 알 수 있게 + 전체 코드
사용자 지적: "전체 코드로 보여줘", "어디에 있는지 모르겠어"(코드 상자가 큰 애니메이션 아래에 있어 안 보임).
- (2026-11-20 사용자 결정: JavaScript 탭 제거, Python·TypeScript만)
- 애니메이션 탭: 카드 줄 **바로 아래에 보기 탭 한 줄** `[▶ 애니메이션] [Python] [TypeScript]` + 오른쪽 [복사]·[새 탭에서 열기 ↗]. 애니메이션 탭이면 iframe, 언어 탭이면 그 자리에 **전체 코드**(iframe 대신). 카드를 바꿔도 선택한 보기 유지(`aiVoiceDash.codeLang`에 'anim'|'python'|'javascript'|'typescript').
- 코드 영역: max-height 제거, 코드 **전체 펼침**(세로 스크롤은 페이지 스크롤), 가로만 스크롤.
- 코드 위 출처 줄을 정확하게: `📓 {노트북 파일명} · Part N 제목 · 코드 셀 a~b번째 (Colab에서 위에서부터 센 코드 셀 순번)` + [노트북 Colab에서 열기 ↗](files의 colab 링크). JS·TS는 `참고용 변환 예시 · 원본: {노트북 파일명} Part N`.
- **전체 코드**: 60줄 제한 없앤다. 그 애니메이션에 해당하는 Part의 코드 셀을 빠짐없이 순서대로 이어 붙인다(셀 사이에 `# ── 코드 셀 k ──` 구분 주석). 맨 위 import 모음 유지. JS·TS도 그 Python 전체 흐름을 빠짐없이 옮긴 완성 코드로 다시 쓴다(줄 수 제한 없음, 실제 존재하는 라이브러리만).

## 3. 과정 지도: 번호 공 → 주차 버튼
- 공 45개 삭제. `[전체] [1주차] [2주차] … [9주차]` 버튼 한 줄(주차 수는 course.json으로 자동, 버튼 색 = 주차 색, aria-pressed).
- 주차 선택 → 그 주 일차 카드 전부(지금 주차 보기 그대로) + 첫 일차(또는 선택 일차) 상세. 해시 `#map-w{n}`, 일차 카드 클릭 `#map-w{n}-d{d}`. 기존 `#map-d{n}`은 그 주차로 열리게 호환.

## 4. 문제 풀이: 10문항 단위 이동 버튼
- sticky 일차 칩 줄 아래(같은 sticky 묶음)에 `[1~10] [11~20] [21~30] [31~40]`(그 일차 문항 수에 맞춰 자동). 누르면 그 번호 문항으로 부드럽게 스크롤(sticky 높이만큼 여백, reduced-motion이면 즉시). 현재 보이는 구간 버튼 강조(IntersectionObserver).
- 문항 카드에 `id="q{n}"`. 검색 중에는 구간 버튼이 걸러진 결과 기준.

## 5. "오늘의 흐름에서 보기"로 간 페이지에 이전 페이지 버튼
- 자료실(그래프 정리 등)·과정 지도·홈에서 일차 탭으로 이동했을 때, 그 화면 **왼쪽 위(eyebrow 위)에 `← 이전 페이지로`** 버튼. 누르면 `history.back()`(돌아갈 기록이 우리 페이지면) 아니면 출발 해시로 이동. 출발 해시는 sessionStorage(try/catch) 또는 메모리 변수에 저장.
- 레일 메뉴로 직접 이동한 경우에는 버튼 없음.
